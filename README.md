# 🎨 Pixel Art Studio (Free Edition)

> **macOS 스타일 다크모드 지원 & AI / Vibe Coding 연동에 최적화된 경량 픽셀 아트 제작 PC 프로그램**

Electron 기반으로 제작된 순수 픽셀 아트 편집 툴입니다. 사람이 직접 그릴 수도 있고, AI 에이전트(Cursor, Claude Code 등)가 2D 배열 데이터를 활용해 자동으로 픽셀 에셋을 생성하고 게임 개발 프로젝트에 연결할 수 있도록 설계되었습니다.

---

## ✨ 주요 기능 (Key Features)

- 🎨 **모던 다크모드 UI:** macOS 감성의 반투명/라운드 디자인 및 다크 테마 적용
- 🛠️ **그리기 툴킷:** 펜(Pencil), 지우개(Eraser), 페인트통(Bucket Fill), 스포이트(Color Picker), 전체 초기화
- 📐 **그리드 옵션:** 16x16 / 32x32 그리드 사이즈 변경 및 그리드 선 토글(ON/OFF)
- 🎨 **컬러 팔레트:** 기본 레트로 컬러 칩 8종 + 자유 색상 선택기
- 🤖 **AI / Vibe Coding 연동 지원:** 픽셀 데이터를 2D Array / JSON 형태로 처리하여 AI 에이전트의 자동 에셋 생성 호환
- 💾 **PNG 내보내기:** 픽셀이 흐려지지 않는 고화질 PNG 이미지 추출
